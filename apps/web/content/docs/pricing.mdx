RedNest access is based on GitHub identity and, after launch, verified $NEST holdings. There is no monthly or annual SaaS subscription required for the public $NEST holder model.

> **Token-holder scanning is not active yet.** Wallet verification is available ahead of the official $NEST launch. No official mint is configured, and RedNest does not sell $NEST.

## Start scanning for free

**Allowance:** 1 lifetime scan per authenticated GitHub account.

- Sign in with GitHub.
- Run one eligible security scan (for example a public [Quick Scan](/docs/quick-scan)).
- No $NEST token required.
- No recurring subscription.

[Start Free Scan](/dashboard/scans)

## Security scanning powered by $NEST

**Allowance:** 50 scans per UTC month after activation.  
**Eligibility:** Hold at least **50,000 $NEST** in a cryptographically verified Solana wallet.

- Connect a Solana wallet in [Settings](/dashboard/settings#wallet).
- Verify ownership by signing a server-issued challenge (no token transfer).
- Maintain the required balance when requesting holder scans; eligibility is checked server-side.
- Receive up to 50 chargeable scans per UTC month; the allowance resets at the UTC month boundary.
- No recurring fiat subscription is required for holder access.

[Connect Wallet](/dashboard/settings#wallet)

Token-holder scanning is not active yet. Wallet verification is available ahead of the official $NEST launch.

## What uses a scan allowance

One authorized scan allowance is charged for each of:

- [Quick Scan](/docs/quick-scan)
- Manual Dig / deep scan from the dashboard
- Agent or MCP deep scan
- Automatic pull request security review

Accounting follows RedNest’s reservation and settlement rules: an allowance is reserved when a chargeable scan is authorized, then settled when the scan meaningfully starts. A scan that fails, is refused, or never starts does **not** permanently consume that allowance in the usual settlement path. Recon (threat-model mapping) and fix checks are not charged as holder scan allowances.

Organizations can designate a **sponsor** whose allowance funds automatic pull request reviews. Scan allowances are not unlimited: free users get one lifetime scan, and eligible holders get at most 50 chargeable scans per UTC month after activation.

## How holder eligibility works

1. GitHub remains your RedNest identity.
2. You verify a Solana wallet with a signed message ([Solana wallet verification](/docs/wallet)).
3. When holder scanning is activated, RedNest checks the verified wallet’s on-chain $NEST balance against the 50,000 whole-token threshold before reserving a holder scan.
4. Client-reported balances are never trusted.

Until activation, missing mint configuration or a disabled launch flag keeps holder access fail-closed. Your free lifetime scan and GitHub sign-in continue to work.

## Self-hosted

A self-hosted RedNest has hosted billing and $NEST holder gates turned off. You pay only for your own servers and model usage. See [Self-hosting](/docs/self-hosting).
